## About

I build RESTful APIs with **Node.js** and **Laravel** on **MySQL** — JWT auth, clean code, documented endpoints. I run them on **Linux** and **Docker** behind **Nginx**, and I put **MikroTik** firewalls, NAT and **OSPF/BGP** routing in front of them. My code has run inside a production data center, so uptime is a design input, not an afterthought.

Currently finishing S1 Teknologi Informasi at UBSI · learning PostgreSQL, Prisma and Redis.
